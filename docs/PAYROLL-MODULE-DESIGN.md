# การจัดการเงินเดือนใน HR

เปิดหน้า HR → จัดการเงินเดือน เพื่อกำหนดเงินเดือน ตรวจรายการ คำนวณ อนุมัติ และบันทึกจ่ายตามสิทธิ์เดิม

โปรไฟล์พนักงานอยู่ใน HR ส่วนการถ่ายรูปและลงเวลาเข้า–ออกอยู่ใน Check-in การอนุมัติใบลาและการลงเวลานอกพื้นที่อยู่ใน HR

การย้ายระบบไม่ได้คำนวณรอบเงินเดือนเดิมใหม่ ไม่เปลี่ยนประวัติลงเวลา และไม่เปลี่ยนรหัสรายการ สลิปและลิงก์เดิมยังอ้างถึงข้อมูลเดิม

CRM ส่งต่อ URL เดิมมาที่ HR คำสั่งบันทึกจากหน้าเก่าจะไม่ถูกส่งซ้ำ กรุณาเปิดหน้า HR ใหม่ก่อนบันทึก
