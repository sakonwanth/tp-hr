ติดตั้งแอป TP-HR

เพิ่ม TP-HR ลงหน้าจอโฮมของมือถือ เพื่อเปิดใช้แบบเต็มจอเหมือนแอปทั่วไป ไม่ต้องดาวน์โหลดจาก App Store

iPhone / iPad

ต้องเปิดผ่าน Safari เท่านั้น — Chrome หรือ LINE บน iOS จะไม่มีเมนูนี้

  1. เปิด Safari แล้วเข้าเว็บ TP-HR
  2. แตะปุ่ม แชร์ (ไอคอนสี่เหลี่ยมมีลูกศรชี้ขึ้น) ที่แถบด้านล่าง
  3. เลื่อนลงแล้วเลือก เพิ่มไปยังหน้าจอโฮม (Add to Home Screen)
  4. แตะ เพิ่ม มุมขวาบน
  5. ปิด Safari แล้วเปิดแอป TP-HR จากหน้าโฮมได้เลย
เปิดจากไอคอนหน้าโฮมทุกครั้ง — การแจ้งเตือนและการแสดงผลเต็มจอจะทำงานเฉพาะตอนเปิดแบบนี้เท่านั้น

Android

ใช้ Chrome หรือเบราว์เซอร์ที่รองรับ PWA

  1. เปิดเว็บ TP-HR ใน Chrome
  2. แตะเมนู ⋮ มุมขวาบน
  3. เลือก ติดตั้งแอป หรือ เพิ่มลงในหน้าจอหลัก
  4. ยืนยัน ติดตั้ง
